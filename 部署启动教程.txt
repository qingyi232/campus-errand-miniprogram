========================================
    校园跑腿小程序 — 部署启动教程
========================================
    （适用于 Windows 系统，零基础小白版）

本项目技术栈：微信小程序 + Node.js + Express + MySQL
本教程将从零开始，手把手教你安装所有软件并运行整个项目。


========================================
第一步：下载并安装 Node.js
========================================

1. 打开浏览器，访问 Node.js 官网：
   https://nodejs.org/zh-cn

2. 点击下载 LTS（长期支持版），推荐 v18 或 v20 版本
   直接下载 Windows 安装包（.msi 格式）

3. 双击下载的 .msi 文件，一路点击 "Next"，全部默认设置即可
   安装路径建议保持默认：C:\Program Files\nodejs\

4. 安装完成后，验证是否成功：
   - 按 Win+R，输入 cmd，回车打开命令提示符
   - 输入以下命令：
     node -v
     npm -v
   - 如果显示版本号（如 v18.17.0 和 9.6.7），说明安装成功

5. 【可选】配置 npm 淘宝镜像（加速下载依赖包）：
   在命令提示符中输入：
   npm config set registry https://registry.npmmirror.com


========================================
第二步：下载并安装 MySQL 数据库
========================================

1. 打开浏览器，访问 MySQL 官网下载页：
   https://dev.mysql.com/downloads/installer/

2. 选择 "MySQL Installer for Windows"
   点击 "Download" 按钮（选择较大的那个安装包，约 300MB+）
   页面底部会提示登录，直接点击 "No thanks, just start my download" 跳过

3. 双击下载的安装包，开始安装：
   - 选择 "Developer Default" 或 "Server only"
   - 一路 Next
   - 在 "Authentication Method" 页面，选择 "Use Legacy Authentication Method"
     （重要！选这个兼容性更好）
   - 设置 root 密码，建议设为：root123456
     ★★★ 请务必记住这个密码！后面要用 ★★★
   - 其他全部默认，点击 Execute 完成安装

4. 安装完成后，验证是否成功：
   - 按 Win+R，输入 cmd，回车
   - 输入：mysql -u root -p
   - 输入你设置的密码（root123456）
   - 如果看到 mysql> 提示符，说明安装成功
   - 输入 exit 退出

   如果提示 "mysql 不是内部或外部命令"，需要配置环境变量：
   - 右键 "此电脑" → 属性 → 高级系统设置 → 环境变量
   - 在 "系统变量" 中找到 Path，双击编辑
   - 新建一条：C:\Program Files\MySQL\MySQL Server 8.0\bin
     （路径根据你的实际安装位置调整）
   - 确定保存，重新打开 cmd 再试


========================================
第三步：下载并安装微信开发者工具
========================================

1. 打开浏览器，访问微信开发者工具下载页：
   https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

2. 选择 "稳定版 Windows 64" 下载

3. 双击安装包，一路默认安装即可

4. 安装完成后打开微信开发者工具
   - 使用微信扫码登录
   - 登录成功后先不要创建项目，等后面的步骤


========================================
第四步：配置数据库连接
========================================

1. 用文本编辑器（记事本、VS Code 等）打开项目文件：
   server\config\db.js

2. 文件内容如下，根据你的 MySQL 配置修改：

   const mysql = require('mysql2/promise');
   const pool = mysql.createPool({
     host: 'localhost',        ← 不用改
     user: 'root',             ← MySQL 用户名，默认 root
     password: 'root123456',   ← 改成你安装 MySQL 时设置的密码
     database: 'campus_errand',← 不用改
     waitForConnections: true,
     connectionLimit: 10
   });

   ★ 只需要修改 password 字段为你的 MySQL 密码即可
   ★ 如果你安装时密码设的就是 root123456，则不需要修改


========================================
第五步：安装项目依赖并初始化数据库
========================================

1. 打开命令提示符（Win+R → cmd → 回车）

2. 进入项目的 server 目录：
   cd /d 你的项目路径\校园跑腿小程序\server
   
   例如项目在 D 盘：
   cd /d D:\校园跑腿小程序\server

3. 安装后端依赖包（需要等待几分钟）：
   npm install

   如果下载很慢，先执行：
   npm config set registry https://registry.npmmirror.com
   然后再执行 npm install

4. 等待安装完成，看到类似以下输出说明成功：
   added 50 packages in 30s

   ★ 如果 canvas 包安装失败，不影响核心功能，可以忽略
   ★ 如果出现 WARN 警告，可以忽略，只要没有 ERR 就行

5. 初始化数据库（自动创建数据库、表和示例数据）：
   npm run init-db

   看到以下输出说明成功：
   ✓ 数据库 campus_errand 已创建
   ✓ 所有数据表已创建
   ✓ 用户数据已插入
   ...
   ========================================
     数据库初始化完成！
     管理员账号: admin / admin123
     普通用户: 13800001111 / 123456
     商家用户: 13800004444 / 123456
   ========================================

   ★ 如果报错 "Access denied"，说明数据库密码不对
     请回到第四步检查 db.js 中的密码配置


========================================
第六步：启动后端服务
========================================

1. 在 server 目录下执行：
   npm start

   或者：
   node app.js

2. 看到以下输出说明启动成功：
   服务器启动成功: http://localhost:3000
   管理后台: http://localhost:3000/admin

3. ★★★ 重要：这个命令窗口不要关闭！★★★
   关闭窗口 = 关闭服务器 = 小程序无法使用

4. 验证服务是否正常：
   打开浏览器，访问 http://localhost:3000
   如果看到 {"msg":"校园跑腿小程序后端服务运行中","version":"1.0.0"}
   说明后端服务运行正常

========================================
第八步：导入并运行微信小程序
========================================

1. 打开微信开发者工具

2. 点击 "+" 号或 "导入项目"

3. 填写项目信息：
   - 项目名称：校园跑腿小程序
   - 目录：选择项目中的 miniprogram 文件夹
     例如：D:\校园跑腿小程序\miniprogram
     ★ 注意：是选 miniprogram 文件夹，不是根目录！
   - AppID：点击下方 "测试号" 或输入你自己的小程序 AppID
     如果没有 AppID，选择 "测试号" 即可

4. 点击 "确定" 导入项目

5. 导入后，微信开发者工具会自动编译并显示小程序界面

6. 如果左侧模拟器显示空白或报错：
   - 检查后端服务是否在运行（第六步的命令窗口是否还开着）
   - 点击工具栏的 "编译" 按钮重新编译
   - 检查控制台是否有报错信息

========================================
常见问题排查
========================================

Q1: npm install 报错怎么办？
A: 先执行 npm config set registry https://registry.npmmirror.com
   然后重新执行 npm install
   如果 canvas 包报错，可以忽略，不影响核心功能

Q2: 数据库初始化报错 "Access denied"？
A: 检查 server\config\db.js 中的 password 是否和你 MySQL 的密码一致

Q3: 小程序显示空白？
A: 确保后端服务正在运行（node app.js 的窗口没有关闭）
   在微信开发者工具中点击 "编译" 重新编译

Q4: 小程序报 "request:fail" 错误？
A: 在微信开发者工具右上角 → 详情 → 本地设置
   勾选 "不校验合法域名、web-view(业务域名)、TLS版本以及HTTPS证书"

Q5: 图片不显示？
A: 确保后端服务正在运行，图片通过 http://localhost:3000/images/ 提供
   控制台的 HTTP 协议警告可以忽略，不影响本地开发

Q6: 如何重置数据？
A: 在 server 目录下重新执行 npm run init-db 即可重置所有数据

Q7: 端口 3000 被占用？
A: 打开命令提示符，执行：netstat -ano | findstr :3000
   找到占用端口的进程 PID，然后执行：taskkill /PID 进程号 /F
   再重新启动服务

Q8: MySQL 服务没有启动？
A: 按 Win+R，输入 services.msc，找到 MySQL80（或 MySQL57）
   右键 → 启动

│   ├── config/           ← 数据库配置
│   ├── middleware/        ← 中间件（JWT 认证）
│   ├── public/images/    ← 静态图片资源
│   ├── app.js            ← 服务器入口
│   ├── init-db.js        ← 数据库初始化脚本
│   └── package.json      ← 依赖配置

│   └── index.html        ← 管理后台页面
